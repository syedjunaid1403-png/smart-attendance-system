# Smart Attendance Analytics System

This is a complete Smart Attendance Analytics System built using Python Flask, SQLite, Bootstrap 5, Pandas, and Matplotlib. 
It is designed to manage students, record attendance, and provide attendance analytics through a dashboard and reports.

## Features

- **Student Management:** Add, View, Search, and Delete students.
- **Attendance Tracking:** Mark student attendance (Present/Absent) on a daily basis.
- **Dashboard Analytics:** View key performance indicators (KPIs) like Total Students, Present Today, Absent Today, and overall Attendance Percentage.
- **Data Visualization:** View Present vs. Absent as a Pie Chart, and Department-wise Attendance as a Bar Chart.
- **Reports:** View detailed student-by-student attendance summaries.

## Technologies Used

- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Analytics:** Pandas, Matplotlib

## Setup Instructions

1.  **Clone the repository / Navigate to the folder:**
    ```bash
    cd Smart_Attendance_System
    ```

2.  **Install dependencies:**
    It is recommended to use a virtual environment.
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the application:**
    ```bash
    python app.py
    ```

4.  **Access the web app:**
    Open your browser and navigate to `http://127.0.0.1:5000`
